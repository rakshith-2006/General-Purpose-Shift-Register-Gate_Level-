# General-Purpose-Shift-Register-Gate_Level-
RTL-to-GDSII physical design of a 101101 Sequence Detector &amp; a Shift Register (16 SRAMs) using Synopsys tools and the SAED 32nm student library. To overcome missing tie/endcap cells in the academic lib, dcap cells were used as workarounds to resolve spatial errors and achieve clean placement.
